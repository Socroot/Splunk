# 🔍 Splunk Security Resources

A collection of practical Splunk resources designed for SOC Analysts, Blue Teamers, Detection Engineers, and security professionals focused on security monitoring, threat hunting, and log analysis.

This repository contains Splunk dashboards, detection use cases, hunting queries, and security analytics resources to help improve SOC visibility and incident detection.

## 📂 Available Resources

- **Macro Hunting Dashboard** – Splunk dashboard for detecting and analyzing suspicious Office macro activities and related endpoint behaviors.

More Splunk dashboards, detection rules, and security monitoring resources will be added regularly.
